Fun Park Zoo Community Hub

Website Design & Planning Document

Site Name

Selected Name: Fun Park Zoo Community Hub

Reason for Choice: I picked this zoo because I love local community spots that make nature accessible to everyone, and its straightforward layout makes it fun and easy to design.

Site Purpose

The purpose of this website is to serve as an accessible, friendly gateway for the local community to connect with Fun Park Zoo. It provides streamlined access to essential visitor information, showcases an interactive animal experience catalog, and offers a straightforward path for community members to support the zoo through volunteering.

Target Audience Scenarios

The content and navigation of the site will be structured to instantly answer common visitor inquiries, such as:

  • Scenario 1: "What are the current admission prices and opening hours for families visiting this weekend?"
  • Scenario 2: "How can I sign up to help with the zoo's community education programs or volunteer with the animals?"

Color Schema

The website uses the selected color palette:

Primary Green (#2E6F40)
Used for headings, main header sections, and primary navigation highlights to establish the nature identity.
Secondary Earth (#D9A05B)
Used for active states including button components to provide clear visual contrast.
Dark Charcoal (#2B2D2F)
Used for body contrast against the light neutral background.

Typography

The site utilizes a structured sans-serif typography system:

  • Headings (H1, H2, H3): Bold Sans-Serif (Segoe UI / Tahoma).
  • Body Text and Paragraphs: Regular Sans-Serif (Segoe UI / Verdana)
